Varanasi 0–3 Hour Nowcast

Time-stepped scenario showing how rainfall can evolve into street-level flood risk.

Interpretation

As rainfall intensity rises, runoff generation increases. Where terrain concentrates flow and drainage capacity becomes constrained, the coupled model raises predicted water depth and risk. This demonstration uses simulated values; the production model would use validated rainfall, DEM, land-use and drainage inputs.

Important prototype boundary

The basemap is real Varanasi OpenStreetMap data. The flood polygons, drainage assets, rainfall values and risk values displayed by this prototype are deliberately marked as scenario/demo data. Do not present them to judges as measured Varanasi flood observations.

Varanasi Prototype Data Sources

Basemap: OpenStreetMap centered on Varanasi.

Rainfall: radar / gauge / forecast grid can be connected through an API.

Terrain: Digital Elevation Model (DEM).

Urban data: roads and land-use layers.

Drainage: nodes, pipes, capacities and blockage indicators.

Flood model: rainfall → runoff → surface flow → drainage coupling → depth/risk.

Prototype note: scenario values are for demonstration and must be replaced/validated with authoritative local datasets before operational use.
